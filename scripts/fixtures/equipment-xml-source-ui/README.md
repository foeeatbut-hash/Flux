# Проверка панели XML источника оборудования

Запустить из корня Flux:

```sh
npx vite --config scripts/fixtures/equipment-xml-source-ui/vite.config.ts --host 127.0.0.1 --port 4192
node scripts/fixtures/equipment-xml-source-ui/check.mjs
node scripts/fixtures/equipment-xml-source-ui/importer.check.mjs
```

Проверка проходит сценарий предварительного просмотра и явного подтверждения
привязки, затем сравнение ревизии B. Она проверяет одиночный перенос папки
через preview, подтверждение с CAS и отмену локальной привязки, включая пустое
локальное хранилище и конфликт с записью после preview. Окно обновлений проверяет
счётчик проекта, состояния pending/partial/no-diff/ошибка, выбор двух тегов,
массовую перепривязку и undo, последовательное решение в существующих карточках,
права чтения и переключение проекта при запоздалом ответе. Проверка снимает UI
при ширине 360 и 1100 точек и проверяет отсутствие горизонтального переполнения.
Панель источника снимается в светлой и тёмной темах; окно обновлений также
проверяется в обеих темах.
Отдельная проверка импортера подтверждает, что серверный план не применяет
изменения до кнопки подтверждения, а локальная привязка сохраняется только после
успешного импорта. Панель также проверяет решение по структурному изменению и
его отмену.
