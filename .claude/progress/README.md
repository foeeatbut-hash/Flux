# Файлы хода исполнителей

Здесь исполнитель ведёт `<имя-задачи>.md`: шаги, отметки, на чём остановился.
Нужно, чтобы после обрыва сессии работа продолжилась, а не началась заново.
Файлы живут, только пока задача идёт: в финальном коммите исполнитель их
удаляет. Правило — в `.claude/agents/flux-executor.md`, раздел «Контрольные точки».
