# demo-video — презентационное видео Flux

Задание: scripts/demo-video/{record.ts,overlay.ts,run.sh} — запись основного пути
(база -> теги -> документы/выгрузка) в Chromium с курсором и подписями, mp4 H.264
1920x1080. Ветка claude/pensive-tesla-litgf1, ревизия старта 40289d1.
Порт: DEMO_PORT (по умолчанию 3187), 3000 не трогаем.

Шаги:
- [x] разведка экранов, xlsx из scripts/fixtures/blanks.ts
- [x] overlay.ts (курсор, подпись, рамка, всплывашка, заставки)
- [x] record.ts черновой прогон DEMO_FAST=1
- [x] полный прогон со сценарием 0-11 без падений (титры-переходы, связи в дереве)
- [x] запись видео (357,6 с, 1920x1080 H.264), ffprobe, кадры по шагам
- [x] коммит scripts/demo-video/* и этого файла

Заметки: имя файла xlsx — только ASCII (кириллическое имя мастер импорта не принимает);
"Выпустить документы" падает при позициях без тегов — позиции заполняем полностью.

Итог: PDF и Проводник в браузерной сборке недоступны (печать / «работает в Flux для Windows»), выгрузки в Excel из тегов и закупок уходят в «Выгрузки» и открывают пустой редактор (нет GenOffice) — окно закрывается в сценарии. Осиротевший сервер после падения гасить по PORT=3187 в environ.
