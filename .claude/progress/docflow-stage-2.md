каталог проекта — catalog.project (в 2а не вводить). Не копировать при выдаче,

сверка версии, срок жизни/уборка. Пользователь видит область действия.
Новые экраны/маршруты/наборы сразу в verification/manifests и workflows;
мутация каждого нового набора обязана давать красный результат. Три схемы,
security-db, prisma generate для всех трёх. Не коммитить сгенерированные
prisma-clients/*/package.json. UI ждёт состояния, обе темы без прозрачности;
