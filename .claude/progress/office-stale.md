# Office: полоса «устарело» — снятые позиции и пропавшие значения

Решение владельца (4.11.2026): перед «Обновить» показать, что и как поменяется
в документе, в том числе для позиций, которых больше нет в источнике, и для
значений, пропавших из источника. Сейчас «Обновить» их не трогает и полоса
висит до «Скрыть» (решение 25.10, закреплено в `test-office-changes`,
`count == 2`).

Предложение (на приёмку владельцем по предпросмотру):
- предпросмотр «Обновить»: список «было → станет» по каждой ячейке;
  отдельной группой — «позиция снята: строка будет помечена», «значение
  пропало: ячейка будет очищена/помечена»; галочки — что применять;
- строка снятой позиции не удаляется, а помечается; после применения полоса
  уходит;
- откат одним действием.

Файлы: `src/components/office/FluxOfficePanel.tsx`, `FluxChangesList.tsx`,
`server/officeChanges.ts`; страница `docs/methodology/03-programs/office.md`.
Ждёт свободного исполнителя.
