# Flux Владелец

Flux Owner — portable-программа для владельца компании. Для текущего сценария используйте Flux `1.20.3` и Flux Owner `1.2.0` в одной папке. Откройте существующее новое хранилище владельца его паролем; создавать ключи заново не нужно.

## Подключение

В разделе «Подключение» введите URI MariaDB, например `mysql://USER:PASSWORD@HOST:3306/Flux`. Пример вымышленный: замените пользователя, пароль, хост и имя базы своими значениями. Пароль скрыт в поле ввода, а после успешного подключения поле очищается. Не публикуйте URI с настоящим паролем.

Flux Owner автоматически найдёт Flux portable в той же папке и запустит его серверную часть локально, без окна. Если файл не найден, Owner предложит выбрать EXE. Node.js, SSH и установка службы на NAS не нужны. После входа нажмите «Открыть Flux как владелец».

Для самостоятельного использования настольного Flux настройте общую базу в панели подключения Flux и перезапустите программу. URI `mysql://...` является SQL-подключением к MariaDB, а не HTTPS URL. Для уже работающего общего API есть расширенный вариант: подключение Owner к HTTPS-адресу сервера Flux.

Убедитесь, что MariaDB доступна по TCP на порту `3306` с компьютера пользователя и что отдельная учётная запись приложения имеет права на базу. Подключение phpMyAdmin к `localhost` через UNIX socket не подтверждает сетевой доступ или удалённые права. `root@localhost` не следует использовать как пользователя приложения.

## Лицензии и обновления

Выдавайте лицензии и публикуйте обновления существующим комплектом ключей Owner. Обновления Flux Owner устанавливаются вручную отдельным portable EXE. Если текущая сборка Flux закреплена за другими открытыми ключами, установите сборку с актуальными ключами вручную и перевыпустите лицензии.

## Сборка

Из каталога `tools/flux-owner`: `npm ci`, `npm test`, `npm run build`. Windows portable собирается GitHub Actions `build-owner.yml` и публикуется под тегом `owner-v<версия>`. Сборка Owner — отдельный portable EXE; обновление Owner выполняется вручную.
