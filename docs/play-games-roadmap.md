# Следующие игры Flux Play

В каталоге уже доступны сетевые реверси, шашки, морской бой, шахматы, «Четыре в
ряд» и покер с обменом на двоих. Встроенный сервер принимает ход, проверяет
правила и записывает состояние в общую базу; второй сотрудник видит следующий
снимок матча. 2048 и судоку остаются одиночными.

1. **Дурак на двоих.** Знакомая короткая карточная игра; нужны козырь, добор,
   лимит подкидывания, скрытая рука и корректное завершение при пустой колоде.
   После реализации на двоих можно расширять до четырёх.
2. **Командная викторина.** Вопросы из локального каталога, ответы и таймер
   считаются сервером, команды видят счёт в реальном времени. Администратор
   сможет создавать наборы вопросов. Для отдела полезнее тем по рабочим данным
   без передачи этих данных наружу.
3. **Техасский холдем на 2–6 сотрудников.** Нужны общий стол, несколько
   раундов торговли, корректный расчёт побочных банков и исходов при нескольких
   победителях. Текущий контракт результата (`winnerTeam`) и сдача в матче
   рассчитаны на дуэль: до расширения протокола нельзя объявлять холдем готовым.
4. **Кооперативная игра в слова.** Команда вместе угадывает слово по подсказкам
   за ограниченное число ходов; сервер хранит тайное слово и не отдаёт его до
   конца партии. Подходит для быстрых перерывов с четырьмя и более участниками.

Для всех следующих игр остаются обязательными право доступа от администратора,
скрытый раздел при выключении платформы, проверка каждого хода на сервере,
идемпотентность команды и отсутствие реальных денежных ставок.
