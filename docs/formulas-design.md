# Формулы документа: плашки с названием

## Что не так сейчас

В шаблоне титульного листа поле вставляется плашкой с человеческим названием
(«Название документа»), а формула — плашкой с выражением: `ƒ date & " г."`.
Инженер видит в документе кусок кода. Собрать составное значение может только
тот, кто помнит синтаксис, а изменить порядок «день-месяц-год» нельзя вовсе —
дата приходит уже собранной строкой.

## Что должно быть

Формула — **именованная вещь**, а не строка выражения. В документе видно
название: «Дата», «Инициалы сотрудника», «Подпись», «Шифр с ревизией».
Настройка формулы живёт в её карточке, а не в тексте документа.

```
┌─ титульный лист ──────────────────────────────────────┐
│  Разработал   [Инициалы сотрудника]  [Подпись]        │
│  Дата         [Дата]                                  │
│  Документ     [Шифр с ревизией]                       │
└───────────────────────────────────────────────────────┘
```

## Устройство

### Формула = название + вид + настройка

Четыре вида, от простого к сложному. Три первых собираются мышью, четвёртый —
для тех, кому нужно считать.

| Вид | Что делает | Пример |
|---|---|---|
| **Значение** | одно поле программы, с настройкой вывода | «Дата» — поле `date`, порядок Д.М.Г |
| **Текст** | постоянная надпись | «г.», «Лист» |
| **Сборка** | несколько частей подряд с разделителями | «Шифр с ревизией» = шифр + « рев. » + ревизия |
| **Выражение** | как сейчас: `+ - * / &`, скобки, поля | `pages - page & " осталось"` |

**Сборка** — главное, ради чего всё затевается. Строка частей, каждую можно
переставить, убрать, заменить.

Разделитель принадлежит части и ставится **перед** ней — и печатается, только
если слева уже что-то есть. Привязка «после части» кажется естественнее, но
ломается ровно на том, ради чего затевалась: убрав пустую ревизию, мы оставляли
«ПЗ-001 рев. » — разделитель принадлежал шифру и печатался сам по себе. Это
поймала проверка, а не глаз.

### Настройка «Значения»

У поля-даты — порядок и вид, ровно то, что просили:

```
Порядок   ( Д.М.Г )  ( М.Д.Г )  ( Г-М-Д )
Месяц     ( 05 )  ( мая )  ( Май )
Год       ( 2026 )  ( 26 )
Разделитель  [ . ]
                            → 16.08.2026
```

У поля-человека — как показать: `Иванов Иван Иванович` · `Иванов И. И.` ·
`И. И. Иванов` · `Иванов`. Это и есть «Инициалы сотрудника» — не отдельное
поле в базе, а вид вывода того же ФИО.

Предпросмотр значения показывается прямо в карточке и пересчитывается на
каждое изменение. Гадать не приходится.

### Подпись сотрудника

Новое поле профиля: картинка подписи. Ставится **четырьмя способами**, потому
что у людей по-разному:

- **выбрать файл** — если есть сканер;
- **перетащить** в окно — если файл уже на рабочем столе;
- **вставить из буфера** (Ctrl+V) — сфотографировал телефоном и скинул себе;
- **нарисовать мышью** прямо в окне — если сканера нет вовсе. Без этого
  человек без сканера просто не заведёт подпись.

Порог фона **подбирается по самой картинке**: считаем, где кончается бумага,
и ставим ползунок туда. Крутить вслепую не приходится, но можно поправить.

Поля скана **обрезаются по росчерку** автоматически. Без этого подпись в
документе выходит крошечной: лист отсканирован целиком, подпись занимает в нём
пятую часть, а высота в миллиметрах задаётся всей картинке вместе с полями.

Свою подпись человек ставит **сам — из своего профиля**: раздел «Сотрудники»
открыт только администратору, и иначе рядовой инженер не завёл бы её вовсе.
Чужую меняет только тот, кому доверено управление сотрудниками: подпись — как
личная печать.

Хранится картинкой в самом профиле. Ссылку на чужой адрес не принимаем — иначе
документ полез бы в сеть при каждой печати. Список сотрудников картинок не
содержит: он тянется на многих экранах, и три десятка подписей означали бы
лишний мегабайт на каждый запрос — в списке только признак «подпись есть».

- принимается PNG/JPG, хранится в профиле;
- кнопка **«Убрать фон»**: близкие к белому точки делаются прозрачными,
  порогом можно двигать. Скан с листа сразу годится, обрезать в редакторе
  не нужно;
- в карточке подписи задаётся **высота в миллиметрах** — подпись в документе
  не должна прыгать от того, каким разрешением её отсканировали;
- в документе плашка «Подпись» подставляет картинку по высоте строки.

Чья подпись — часть настройки формулы: **автора документа**, **текущего
пользователя** или **выбранного сотрудника** (для строк «Проверил»,
«Утвердил»).

### Где живёт справочник

Одно место: **Настройки → Документооборот → Формулы**. Оттуда же открывается
кнопкой «＋ Новая формула» из панели вставки в редакторе титула — чтобы не
уходить из документа ради одной формулы.

Формулы **проекта**: их видят все, кто работает над проектом, иначе титул у
коллеги соберётся иначе. Встроенные (Дата, Автор, Подпись, Шифр, Ревизия,
Проект, Заказчик, Страница) идут с программой, их нельзя удалить, но можно
скопировать и переделать под себя.

## Что меняется в коде

| Где | Что |
|---|---|
| `prisma/schema.prisma` | модель `DocFormula`; поле `signatureImage` у `User` |
| `src/screens/titleTemplate.ts` | плашка по идентификатору формулы; сборка и форматы; старые плашки с выражением продолжают работать |
| `src/screens/TitleTemplateEditor.tsx` | список формул вместо поля ввода выражения |
| `server/routes/constructor.ts` | чтение и запись формул, отдача подписи в контекст |
| `src/screens/UsersManagement.tsx` | загрузка подписи в карточке сотрудника |
| `server/routes/users.ts` | сохранение подписи |

Старые шаблоны не ломаются: плашка `data-formula="выражение"` остаётся
работающей, новая — `data-formula-id`. Разбор в `renderTitleHtml` различает их
по атрибуту.

## Чего сознательно не делаем

- **Не даём формулам считать по всему проекту.** Своды по тегам и оборудованию
  уже есть в Конструкторе (`pSum`, `countTag` и прочие). Формула титула — про
  оформление документа, и смешивать эти два языка значит получить третий,
  который никто не знает.
- **Не автоматизируем распознавание подписи.** «Убрать фон» — порог по яркости
  с ползунком и предпросмотром, а не угадывание. Инженер видит результат до
  того, как нажмёт «Сохранить».
- **Не заводим личные формулы.** Документ общий; личная формула у автора
  означает, что у коллеги титул соберётся иначе, и это заметят на печати.

# Что может пойти не так: разбор ситуаций

Ниже — ситуации, которые случатся в отделе на самом деле, и решение по каждой.
Смысл списка простой: пока решение не принято здесь, оно будет принято случайно
в коде, и обнаружится на печати за час до сдачи.

## Пустые значения

| Ситуация | Решение |
|---|---|
| У документа ещё нет ревизии, а перед частью «Ревизия» стоит разделитель « рев. » | Часть выпадает вместе со своим разделителем. В титуле «ПЗ-001», а не «ПЗ-001 рев. » |
| Пусты все части сборки | Плашка даёт пустую строку. Строка штампа остаётся, потому что её рисует шаблон, а не формула |
| Поле есть, но пустая строка с пробелами | Считается пустым: перед проверкой строка обрезается |
| Число 0 | **Не** пустое. «Лист 0» — ошибка данных, и её надо видеть, а не прятать |
| В предпросмотре карточки нет открытого документа | Показываем на примерных данных и подписываем «на примере» — чтобы не выдать образец за реальность |

## Формула, которая уже вставлена в документы

| Ситуация | Решение |
|---|---|
| Формулу переименовали | Плашки ссылаются на идентификатор, а не на название. Название в открытых документах обновится при следующем открытии — это и есть смысл именованной формулы |
| Формулу удалили | Удаление спрашивает и показывает, **в скольких шаблонах** она используется. После удаления плашка рисуется зачёркнутой с подписью «формула удалена», значение — пустое. Документ не ломается и не теряет остальной текст |
| Формулу удалили и завели заново с тем же названием | Это другая формула: у неё другой идентификатор. Старые плашки останутся «удалёнными». Поэтому удаление и предупреждает |
| Настройку формулы поменяли | Все документы, где она стоит, начнут собираться по-новому. Так и задумано: одно место правки. При сохранении показываем, сколько шаблонов затронуто |
| Две формулы с одинаковым названием | Разрешено, но при сохранении предупреждаем: в панели вставки их будет не различить |

## Ссылки формул друг на друга

| Ситуация | Решение |
|---|---|
| Сборка ссылается на другую сборку | Разрешено, вложенность до 5 уровней |
| Формула ссылается сама на себя (прямо или через цепочку) | Запрещаем **при сохранении**, а не при выводе: показываем цепочку «A → B → A». Ловится обходом в глубину |
| Глубина больше 5 | Обрываем и подставляем пустое, в журнал — предупреждение. Пять уровней покрывает любой осмысленный штамп |
| Часть ссылается на удалённую формулу | Ведёт себя как пустое значение, в карточке часть подсвечена как «формула удалена» |

## Сотрудник и подпись

| Ситуация | Решение |
|---|---|
| У сотрудника нет подписи | Плашка даёт пустое место. **Не** подставляем ФИО вместо подписи: подпись — это подпись |
| Сотрудник уволен (профиль отключён) | Подпись и ФИО в уже подписанных документах остаются. Документ — свидетельство того, что было, а не текущего состояния штата |
| Сотрудника удалили из базы | В контексте документа остаётся то, что было записано в документе на момент сохранения. Живая ссылка на удалённого даёт пустое |
| Сотрудник сменил фамилию | Новые документы соберутся с новой, старые сохранённые — со старой |
| Формула «Подпись выбранного сотрудника», а сотрудник не выбран | Пусто; в карточке формулы поле обязательное и подсвечено |
| Загружают не картинку | Отказ с понятным текстом: «Нужен PNG или JPG» |
| Картинка больше 2 МБ | Уменьшаем до высоты 300 точек перед сохранением — подписи такого размера с запасом хватает на печать |
| Подпись со сплошным белым фоном | «Убрать фон» с порогом; по умолчанию порог не применяется, пока человек его не тронул |
| Подпись на клетчатом листе | Порог уберёт светлое, клетка может остаться. Это видно в предпросмотре — решение за человеком |
| Тёмная тема | Подпись рисуется на белой подложке в документе: документ печатается на белом, и тёмная тема к нему отношения не имеет |

## Даты

| Ситуация | Решение |
|---|---|
| «16 августа 2026» — месяц в родительном | Вид «августа» даёт склонённую форму; «Август» — именительную. Обе нужны: первая в строке даты, вторая в заголовке |
| Часовой пояс | Дата берётся по времени машины. Сервер и клиент в одной сети одного офиса |
| Дата документа vs сегодняшняя | Разные поля: «Дата» — сегодня, «Дата документа» — из карточки. В названии видно, какая где |
| Год двумя цифрами на рубеже века | Берём две последние цифры года, без выдумок |
| Пустая дата у поля-даты из карточки | Пусто, а не «01.01.1970» |

## Права и совместная работа

| Ситуация | Решение |
|---|---|
| Кто заводит формулы | Право `dictionaries.manage` — то же, что на справочники. Отдельное право заводить не нужно |
| Кто правит встроенные | Никто. Их можно скопировать и править копию |
| Двое правят одну формулу | Последнее сохранение побеждает, но при открытии карточки показываем, кто и когда менял последним |
| Инженер без права | Видит список и вставляет плашки, кнопки правки скрыты |

## Проекты и перенос

| Ситуация | Решение |
|---|---|
| Шаблон титула скопировали в другой проект | Формулы проекта туда не переезжают. При открытии показываем, каких формул не хватает, и предлагаем **скопировать их одним нажатием** |
| Формула нужна во всех проектах | Копированием. Общий справочник на всю программу не заводим: правка «для одного проекта» тихо поменяла бы титулы у соседей |

## Ввод и правка в документе

| Ситуация | Решение |
|---|---|
| Плашку вставили в середину слова | Разрешено: плашка — самостоятельный элемент, текст вокруг не рвётся |
| Backspace на плашке | Удаляет её целиком, а не по буквам. Плашка `contenteditable=false` |
| Плашку скопировали и вставили в другой документ | Работает: в разметке остаётся идентификатор |
| Плашку вставили в шаблон другого проекта | См. перенос выше |
| Текст плашки попробовали править вручную | Нельзя: содержимое не редактируется, правка идёт через карточку |

## Совместимость и вывод

| Ситуация | Решение |
|---|---|
| Старые шаблоны с плашками-выражениями | Продолжают работать. Разбор различает `data-formula` (выражение) и `data-formula-id` (именованная) |
| Печать и выгрузка в Word | Плашка подставляется значением до вывода — в файл уходит текст и картинка подписи, а не разметка |
| Неизвестное поле в выражении | Пусто, как и сейчас. Ломать вывод из-за опечатки в одной формуле нельзя |
| Битая настройка в базе (руками правили JSON) | Формула отдаёт пустое, в журнал — запись с её названием. Документ открывается |
| Сто плашек на листе | Каталог формул читается один раз на документ, подстановка идёт по словарю в памяти |
