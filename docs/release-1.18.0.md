# Flux 1.18.0 — изменения для сотрудников

* Нажатие на тег открывает панель переходов к карточке, оборудованию и документам.
* Дочерние позиции оборудования показаны отдельными ветвями, включая несколько приводов одного клапана.
* «Выгрузка данных» получила перемещаемое окно с рабочей таблицей, формулами, группировкой и сохранением книги в шаблон.
* В редакторах появился раздел Flux для данных проекта, перевода и выгрузки из разделов программы.
* Каталог поддерживает разные виды оборудования и изготовителей, импорт Excel и 76 исполнений приводов НЕМАН из каталога 2026 года.
* Для характеристик можно выбрать XML, каталог или их сочетание; ручные значения сохраняются.
* Добавлены связь с разработчиком в Телемосте и автоматическое выявление технических сбоев по журналам.
* Обновление не требует переноса существующих данных; зеркало папок Windows подготовлено как проект следующего этапа.

## Проверки и ограничения

Проверены типы, архитектура, сборки фронтенда/сервера/Electron, разбор каталога,
импорт и отмена Excel, источники параметров, иерархия оборудования, обновление
книги и базовый сценарий программы. Автоматическая диагностика проверена
через API с разными правами. Работа с почтовым сервером и запуск portable на
реальном Windows требуют отдельной проверки. Каталожные карточки приводов
содержат отметки о неполных данных исходного PDF; пробелы не заполнены догадками.

Подробности: [Каталог и выгрузки](catalog-and-export.md),
[Проект проводника Windows](windows-explorer-mirror.md).
