# Flux 1.21.0 — список изменений для сотрудников

- Программы Flux могут иметь собственный экран: разработчик рисует окно кодом (поля ввода, кнопки, таблицы, графики, картинки), и оно показывается во Flux так же, как форма. Прежние программы с формой работают без изменений.
- Программа может состоять из нескольких страниц и открывать свои окна как обычные окна Flux. Предложить сохранить файл она может только через вопрос Flux; исполняемые типы файлов отклоняются.
- Страница не выходит в сеть сама: данные Flux она читает по разрешениям, а внешние адреса — только через заявленные подключения. Запись в данные Flux по-прежнему невозможна.
- Если страница программы перестала отвечать, Flux показывает «Программа не отвечает» и предлагает перезапустить её; остальной Flux продолжает работать.
- В Flux Studio появилась заготовка «своя страница» для каждого языка и проверка перед отправкой для таких программ.
- Программы со своей страницей требуют Flux 1.21.0 или новее; на более старом Store покажет «обновите Flux». Обновление не требует действий от сотрудников.

## Границы проверки

Проверено на Linux и в сборках Windows. Пробный запуск страниц в Studio владельца, разрешения на интернет по хостам и вызовы между программами не входят в этот выпуск.
