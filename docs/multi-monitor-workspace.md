# Рабочий стол на нескольких мониторах

В **Параметры → Общие → Мониторы** включите «Рабочий стол на всех мониторах».
По умолчанию Flux открывается обычным окном. Сочетание **Ctrl+Alt+M** переключает
режим; кнопка монитора возле Пуска возвращает в обычное окно с любого экрана.
Выбор сохраняется на этом компьютере.

В общем режиме Flux занимает виртуальный рабочий стол Windows. У каждого
монитора есть своя панель задач. Окна редакторов перетаскиваются между экранами
без переоткрытия документа: состояние редактора и несохранённые правки живут
в одном renderer. Двойное нажатие по заголовку, разворачивание, прилипание к
краю и доли экрана используют рабочую область одного монитора. Панели Windows
и Flux исключены из области редактора. Новые окна появляются на мониторе,
на котором выполнено действие. Панели уведомлений и помощника открываются
у правого края активного монитора. Панель управления самим Flux также остаётся
на активном экране.

Переход к другому файлу из окна редактора открывает отдельное окно, если
раздел поддерживает несколько файлов. Исходный редактор остаётся смонтированным
со своими несохранёнными правками; закрытие этого окна запускает его обычную
проверку и сохранение.

При отключении монитора недоступные заголовки окон возвращаются на ближайший
доступный экран. Начало виртуального стола пересчитывается: мониторы слева и
выше основного могут иметь отрицательные координаты. Окна с доступным
заголовком могут пересекать границу двух экранов. Значки рабочего стола и
файлы отображаются на основном мониторе; дополнительные экраны предназначены
для окон программ.

Геометрия использует DIP из `Electron.screen`, а не физические пиксели:
`scaleFactor` не применяется повторно. Один Chromium renderer использует
единый масштаб отрисовки, поэтому на мониторах с разным DPI текст может быть
менее чётким. Это ограничение отображается в настройках. Независимая резкость
на каждом мониторе потребует отдельных native окон редакторов с отдельным
протоколом сохранения состояния; текущий режим не выдаёт себя за такой вариант.
Если размер объединённого пространства превышает 32767 DIP по любой оси,
Flux сохраняет обычный оконный режим.

## Проверка

`node --import tsx scripts/test-display-workspace.ts` проверяет геометрию и
реальные команды хранилища: отрицательные координаты, экран сверху, разрывы
расположения, разные DPI, отключение монитора, сохранение окна/адреса/размера,
разворачивание и раскладку со свёрнутыми окнами.

`node --import tsx scripts/test-displays-native.ts` дополнительно проверяет
native-контракт Electron на изолированной модели окон: границы, горячее
подключение, восстановление размера, сохранение режима и отказ чужому renderer.

На Windows требуется проверить два физических монитора, разные масштабы,
перестановку основного экрана и отключение кабеля во время редактирования.
После переноса проверьте Ctrl+S, раскрытие Пуска и часов на каждом экране,
панель управления Flux, выход из режима и восстановление размера обычного
окна. Автоматические проверки геометрии не заменяют проверку DPI Windows.

Текущее ограничение одного renderer касается и Windows Alt+Tab: система видит
один Flux, а переключение между редакторами выполняется панелью задач Flux и
его внутренними сочетаниями. Включение режима не создаёт дополнительные
операционные окна с копиями одного документа.
