# Архиватор Flux

ZIP и 7z можно создавать из файлов и папок Flux, задавать степень сжатия и пароль. Просмотр показывает путь, размер, папки и признак шифрования; проверка проверяет содержимое, а не только таблицу файлов. ZIP сохраняет имена записей открытыми даже с паролем; 7z может скрывать заголовки.

Распаковка начинается с выбора записей и предпросмотра. Применение сверяет содержимое архива и создаёт отдельную папку; существующие файлы не перезаписываются. Изменение ZIP/7z также создаёт отдельную копию: удаление, переименование и добавление файлов можно проверить до записи. Исходный архив остаётся прежним. Пароль результата задаётся отдельно.

Доступны чтение и распаковка ZIP, 7z, RAR, TAR, GZ/TGZ, BZ2, XZ, CAB и ISO. Создание RAR и многотомные архивы не поддерживаются. Ограничения операций: исходник до 256 МБ, распакованные данные до 512 МБ, до 5000 записей, операция до двух минут. Предусмотрены проверки путей, ссылок, совпадений имён Windows и фактического размера распаковки.

Используется закреплённый пакет `7zip-bin-full` версии 26.3.1. Windows EXE и DLL поставляются в ресурсах вместе с `License.txt`; пакет-обёртка имеет MIT-лицензию. 7-Zip распространяется по LGPL с дополнительными условиями unRAR для части кода; они не дают использовать код unRAR для разработки компрессора RAR. Исходники и условия: https://www.7-zip.org/license.txt и https://www.7-zip.org/download.html. Flux не является WinRAR и не использует его торговое имя в интерфейсе.
