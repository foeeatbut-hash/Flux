# Этап 2б: проверка шага 4

В рабочей ветке реализованы каталог проекта, выбор источника в Оборудовании,
право в Сотрудниках и перенос каталога в настройках ДО. Выпуск, возвраты и
сроки (шаг 5) ещё не начаты. Дополнительные исправления приёмки касаются имён по
маске Windows и подсчёта всех неприменённых планов в квоте.

`scripts/test-catalog-project.ts` прошёл: 48 проверок через Express и
временную SQLite, включая неизвестные класс и изготовителя, значения параметров
по умолчанию и серверную проверку числа, диапазона и выбора; также отказ общего черновика без `catalog.edit`, подготовку без публикации и обычную отмену. `scripts/security-db-docflow-stage-2.ts` прошёл на SQLite,
включая закрепление и обновление основы, SQL-уникальность и безопасную отмену.
MariaDB и PostgreSQL для нового сценария ещё не проверены.

Мутации права, проверки версии, сохранения переопределений, SQL-уникальности
и версии при отмене выполнялись по одной с восстановлением исходников; каждая
дала код 1. Логи: `/tmp/flux-project-mutant-{right,cas,override,sql-unique,undo-version}.log`.
Снимки интерфейса обеих тем предназначены для артефакта CI
`flux-verification-evidence`; PNG в репозиторий не кладутся.

Мутация проверки значения параметра по умолчанию дала код 1, после
восстановления тест прошёл с кодом 0
(`/tmp/flux-project-mutant-param-default.log`).

UI каталога прошёл: 32 замера четырёх состояний в двух темах и двух ширинах,
просмотр, редактор, предпросмотр и общий черновик, обычное и непрозрачное оформление; панель инструментов — 40 px, строки
списка и поля формы — 32 px, цвета тем различаются. Результаты замеров —
`/tmp/flux-catalog-project-ui/measurements.json`. Подмена с применением во
время предпросмотра дала код 1 (`actual undefined`, `expected take`), после
восстановления UI-набор завершился с кодом 0. UI Оборудования прошёл после
исправления поиска CSS в стенде; сняты четыре изображения для двух тем и
ширин 1440 и 1024.

Для общего черновика проверены отказ первого запроса 503 и повтор с тем же
новым идентификатором; публикация не вызывается. Мутации десятичного ввода
(`2505` вместо `250.5` при посимвольном вводе) и идентификатора общего
черновика (`project-1` вместо `global-…`) дали код 1, восстановленный
