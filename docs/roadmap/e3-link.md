## Главный блокер

**Настоящий мост (этап C) и демонстрация (E)** пишутся только по журналу
`tools/e3-probe/` с компьютера, где стоит E3. Сигнатуры вызовов COM не
угадывать (`e3-integration.md`, раздел 4.3). Нужно от владельца: запустить
скрипт на компьютере с E3 и прислать zip журнала.

## Что проработать для надёжности

### Подключение
- Все состояния подключения (`e3-integration.md`, раздел 10): E3 не
  установлен, не запущен, запущен без проекта, открыт чужой проект, E3
  занят (модальное окно), E3 упал посреди выгрузки.
- Версии E3: на каких версиях проверено; что делать на другой (запрет или
  предупреждение).
- Лицензия E3: COM работает только при свободной лицензии E3 на этом
  компьютере — понятное сообщение, если её нет.
- Несколько окон E3 на одном компьютере — к какому подключаться.

### Выгрузка
- Обрыв посреди выгрузки и продолжение без дублей — проверено на
  подставном мосте, повторить на настоящем E3.
- Скорость: выгрузка большой установки (сотни блоков) — сколько длится,
  нужен ли прогресс и отмена.
- Ручные правки в E3 после выгрузки: что Flux делает при повторной
  выгрузке (не затирать молча).

### Обратная связь
- Что из E3 возвращается во Flux (атрибуты, номера, листы) и что делать,
  если в E3 удалили блок, связанный с позицией Flux.

### Данные и одновременная работа
- Двое выгружают один проект Flux в E3 одновременно — сверка версий при
  записи `E3Export`/`E3Binding` (этап 0 [offline-work.md](offline-work.md)).
- Без общей базы выгрузка в E3 **запрещена** в первой версии офлайна: связи
  `E3Binding` должны совпадать у всех.
- Таблицы E3 проверить на живых MariaDB и PostgreSQL (остаток раздела 5
  plan.md).

### Модули
- Результат расчёта модуля (например, ВЕРОСА — состав установки) должен
  попадать в выгрузку E3 теми же путями, что ручные данные позиции
  ([modules.md](modules.md)).

### Права
- Право `e3.export` по умолчанию никому не выдано — решить, кому выдать
  перед запуском на реальных проектах.

### Проверки
- Набор проверок на настоящем E3 — только на Windows с установленным E3;
  в CI — подставной мост. Перечень сценариев для ручного прогона владельцем
  — по каждому пункту выше.
