# Режим «ИИ» во Flux Guide

Статус: идея · обновлено 9 ноября 2026

Владелец (9 ноября 2026): на сервере компании работают открытые нейросети
(GLM и др.). Во Flux Guide нужен режим «ИИ», который подключается к ним по
API: ответы по данным Flux, создание файлов, распознавание изображений и т. п.
Данные проектов при этом не покидают компанию. Сейчас — только план, порядок
внедрения не назначен.

## Что уже есть в программе

- Flux Guide — справочник и ответы по данным проекта без нейросети, локально:
  [страница программы](../methodology/03-programs/guide.md),
  `src/guide/engine.ts`, `server/routes/guide.ts`, `server/services/guide*.ts`.
  Ответ уже умеет таблицу, карточку, создание Excel/Word из строк.
- Проект ИИ-чата «узнать / найти / сделать»: [ai-chat-design-v0.24.md](../ai-chat-design-v0.24.md)
  (намерения, действия-кнопки, офлайн).
- Правила записи: навык `flux-data-safety` — план, предпросмотр, применение,
  отмена; права — `src/lib/permissions.ts`, проверка на сервере.

## Как устроено (направление)

1. **Подключение только через сервер Flux.** Адрес и ключ API нейросети
   задаются один раз (сервер Flux / Studio — Владелец); компьютеры
   пользователей ключа не видят. Сервер ведёт пределы (запросы, токены на
   человека) и журнал «кто, когда, сколько» без содержимого. Формат —
   OpenAI-совместимый API (`/v1/chat/completions`), его отдают vLLM, Ollama,
   LM Studio, llama.cpp; модель выбирается настройкой, Flux к конкретной модели
   не привязан.
2. **Третий режим Guide — «ИИ»** рядом со «Справочником» и «Вопросами».
   Сервер нейросети недоступен — Guide работает как раньше, режим «ИИ»
   показывает понятное состояние.
3. **Инструменты нейросети** (вызов функций модели), каждый через те же
   проверки прав, что у человека, — ИИ видит только то, что видит этот
   человек:
   - чтение данных Flux: проекты, оборудование, теги, ВДР, каталог, справочник;
   - распознавание изображений (фото шильдика, скан бланка, кусок схемы,
     снимок экрана) — если у модели есть зрение (например, GLM-4V);
   - создание файлов: Word, Excel, заметка, черновик в Проводнике;
   - предложения изменений (заполнить параметры, связать теги, создать строки
     ВДР) — только как план с предпросмотром; применяет человек, отмена есть.
   Сама нейросеть данные Flux не записывает.
4. **Права:** отдельное право «пользоваться ИИ»; настройка набора
   инструментов (только чтение / + файлы / + предложения изменений).
5. **Без связи с сервером** режим «ИИ» недоступен, остальной Guide работает.

## Подводные камни

- Нейросеть ошибается: всё, что меняет данные, — только через предпросмотр и
  подтверждение; в ответе — источник данных.
- Объём контекста: большие проекты нельзя передать целиком — инструменты
  отдают выборки с пределом строк.
- Нагрузка на сервер нейросети: очередь и пределы на человека.
- Изображения: размер и формат — сжатие перед отправкой, предел.
- Журнал без содержимого вопросов по умолчанию; хранить ли текст — решение
  владельца.
