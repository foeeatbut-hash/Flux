# Отказ от лицензии: только вход по логину и паролю

Статус: идея · обновлено 29 октября 2026

Владелец планирует убрать лицензирование: Flux запускается без ключа,
доступ — только по учётной записи сотрудника.

## Что уже есть в программе

- Экран лицензии — `src/screens/LicenseGate.tsx`; API отвечает 402 без
  лицензии; сервис — `server/licenseService.ts`; в Electron —
  `electron/license.ts`.
- Номер установки берётся из лицензии (`licenseInstallationId`) и нужен
  раздаче обновлений (`server/routes/updateCampaigns.ts`).
- Пустую базу первым открывает владелец подписанным ключом (`server.ts`,
  первый вход); начальная учётная запись отключена (`server/legacyIdentity.ts`).
- Проверки обходят лицензию переменными `FLUX_TEST_LICENSE`,
  `FLUX_TEST_LICENSE_AUTO`.

## Что не убирать вместе с лицензией

- **Подпись выпусков.** Обновления Flux и будущие модули
  ([calc-modules.md](calc-modules.md)) проверяются подписью владельца. Это
  защита от подмены файла в базе, а не лицензия; ключ подписи остаётся.
- **Номер установки** — нужен обновлениям; брать его не из лицензии, а
  создавать при первом запуске.

## Этапы

1. Номер установки отдельно от лицензии.
2. Первый вход в пустую базу: создание первого администратора (через Owner
   или одноразовым кодом), раз ключ лицензии больше не нужен.
3. Убрать экран и проверки лицензии в клиенте, API и Electron; ответы 402
   больше не возникают.
4. Убрать обходы в проверках и сценарии демо-видео (`scripts/demo-video/`
   подменяет `/api/license/status`).
