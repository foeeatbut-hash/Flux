# Проводник

Проводник открывает места Windows, документы Flux и файлы с общим доступом из одного окна.

## Что на экране

- Слева — Рабочий стол, Документы, Загрузки, подключённые папки, «Общий доступ» и вход в документы проекта.
- Сверху — кнопки перехода, адрес текущего места, поиск по имени, вид списка или плиток.
- В центре — содержимое текущей папки или список документов проекта/общего доступа.
- В свойствах файла — сведения Windows и метаданные Flux: проекты, теги, ревизия, ответственный и история.

## Раскладка

- Навигация слева → список объектов по центру → свойства и действия выбранного объекта.
- Путь сверху остаётся главным способом видеть и менять расположение.
- Локальные и сетевые места показываются рядом с внутренними папками «Документы проекта» и «Общий доступ».
- Черновики Flux лежат в выбранном месте виртуально и отмечены «Только в Flux»; публикация сохраняет их в файл Windows.
- Поиск относится к текущему списку; свойства и редкие команды доступны у выбранного объекта.

## Что было смешано

«Файлы Windows», «Общий доступ» и проектный архив раньше открывались тремя программами. Теперь «Проводник» — единственный пункт в Пуске; старые пути переводятся в него, а документы проекта и общий доступ остаются внутренними местами.

## Исключения из общих правил

- Без файлового моста Windows Проводник открывает архив документов проекта, потому что браузеру нельзя выдавать доступ к произвольным папкам устройства.
- Редактирование локального файла открывается отдельным окном редактора, но его местом запуска и сохранения остаётся Проводник.

## Логика

- `/explorer` — единственная запись программы. `/windows-files` и `/shared-files` — сохранённые адреса-синонимы.
- `?projectFiles=1` оставлен для старых ссылок на архив. `?view=shared` открывает папку общего доступа внутри того же окна.
- Данные Windows и локальные черновики продолжают храниться нативной файловой службой; маршруты интерфейса не меняют хранилище.
