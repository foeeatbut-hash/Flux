# Мессенджер

Мессенджер — постоянная корпоративная переписка для проектов и сотрудников. Flux Guide вызывается кнопкой **F** в текущем разговоре и публикует ответ отдельным сервисным сообщением. Звонков и видеозвонков нет.

## Экран

- Слева вкладки **«Чаты»** и **«Сотрудники»**. Каталог сотрудников содержит всех доступных по правам людей, поддерживает поиск по ФИО, должности, подразделению и табельному номеру. Выбор сотрудника открывает единственный личный разговор с ним. Сервис Flux Guide не показывается как сотрудник.
- В «Чатах» доступны фильтры **«Все / Непрочитанные / Группы / Личные»**, поиск названий и отдельный поиск по доступной серверной истории. Строка разговора показывает имя, последнее доступное сообщение, время и реальный счётчик непрочитанного.
- В центре — заголовок разговора, лента и поле ввода. Лента группирует сообщения одного автора, показывает цитаты, файлы, реакции и инженерные ссылки. Старые страницы загружаются выше без потери позиции чтения. Новое входящее сообщение не сдвигает чтение; кнопка перехода к новым сообщениям появляется, когда человек читает выше.
- Справа по умолчанию закрытая панель сведений. Для групп: **«Обзор / Файлы / Теги / Участники»**; для личной переписки: **«Обзор / Файлы / Теги»**. Файлы и теги относятся ко всей доступной истории, а не только к загруженной странице. На узком окне сведения открываются временной боковой панелью поверх переписки.
- Поле содержит вложение, ссылку, снимок экрана, смайлы, F и отправку. Элементы ввода остаются доступными без Guide.

## Раскладка и оформление

- Навигация и список слева; лента в центре; панель сведений справа только по запросу. На узкой ширине правая панель перекрывает переписку и закрывается явно.
- Строки списка — 40 px и две строки: имя/название и пояснение либо последнее сообщение. Это исключение нужно, чтобы различать одноимённые разговоры и видеть контекст без открытия каждого из них.
- Шапка разговора — одна строка 44 px. Главные частые действия находятся рядом с рабочей областью; редкие и опасные действия — в меню.
- В панели сведений — строки и списки без карточек в карточках. Цвета, плотность и тёмная тема следуют `01-design.md`.
- Выключенная F выглядит как обычная кнопка, ввод нейтральный. Включённая F включает рамку ввода толщиной около 2 px в цвете Flux, без свечения и градиента; placeholder — «Спросить Flux Guide…». Над вводом кратко сообщается, что ответ увидят участники; сообщение можно закрыть после первого ознакомления.

## Поведение F

- F влияет только на следующую отправку в текущем разговоре. Запрос сохраняется как сообщение автора с доверенной меткой `guideRequest`; текст сообщения не используется как маркер режима.
- Ответ приходит отдельным сообщением сервисного отправителя Flux Guide. Клиент считает его ответом Guide только по серверной связи `guideReply` и сервисной роли отправителя, никогда по совпадению текста.
- Запрос и ответ связаны точным ID; параллельные вопросы не смешиваются. F остаётся включённой после отправки, сбрасывается при смене разговора и выключена после перезапуска.
- При выключенной F текст не обрабатывается Guide независимо от слов и тегов в сообщении. Ответ в группе видят участники разговора; сервер проверяет доступ каждого получателя до публикации и при каждом последующем чтении.

## Требования к доступу и истории

- Каталог сотрудников, список разговоров, поиск, карточки, файлы, цитаты, пересылка и ответы Guide возвращают только данные, доступные текущему пользователю.
- История сохраняется постоянно. Отзыв доступа скрывает защищённое содержимое при чтении и поиске, не удаляя историческую запись.
- Не показывать вымышленные статусы доставки, прочтения или присутствия. Онлайн/последняя активность отображаются только при наличии достоверных серверных данных.
- Открытие результата поиска или объекта меняет только интерфейс нажавшего пользователя.

## Критерии готовности

1. Каталог сотрудников позволяет найти доступного сотрудника и начать личный разговор без дубля.
2. Фильтры чатов и отдельный серверный поиск работают на всей доступной истории; список показывает настоящее последнее сообщение, время и непрочитанное.
3. Переключение чата сбрасывает F, отправка с выключенной F никогда не вызывает Guide, а доверенные запросы/ответы имеют визуальные метки и точную связь.
4. Входящее сообщение не перемещает читающего от старой позиции; возврат к новым сообщениям работает явно.
5. Правая панель закрыта по умолчанию, вкладки соответствуют типу разговора, файлы и теги доступны по всей истории, узкая панель не сжимает ленту.
6. Обычные сообщения, группы, вложения и ссылки на инженерные объекты работают при отключённом Guide.
