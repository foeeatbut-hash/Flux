# Сотрудники

Назначение — завести сотрудника, выдать и закрыть доступ, увидеть, кто
работает и у кого что истекает. Раздел видит только администратор.

## Что на экране

- Список сотрудников: ФИО, логин, роль, доступ, подпись, дата заведения.
- Отбор: все / работают / закрыт доступ / истекает / без подписи; поиск по
  фамилии, логину и роли; порядок: по фамилии, по роли, сначала новые.
- Присутствие: кто сейчас в программе, кто когда заходил.
- Регистрация сотрудника (окно).
- Карточка доступа (окно): ФИО и пол, логин, роль, пароль, срок доступа с
  предустановками, «Профиль активен», права по функциям со сроками, доступ к
  встроенным программам, удаление профиля.
- Подпись сотрудника (своё окно).

## Раскладка

- Шапка: «Сотрудники» · «N сотрудников» · справа «Добавить сотрудника».
- Панель инструментов: поиск → фильтр со счётчиками → справа порядок.
- Строка присутствия: «Сейчас в программе · N: имена» — сразу видно;
  «Заходили последними» — раскрывается списком по нажатию.
- Таблица: Сотрудник (кружок, ФИО, логин) · Роль (значок цветом роли и
  название) · Доступ (точка и слово) · Подпись (есть / нет — открывает окно
  подписи) · Заведён · «Изменить» при наведении. Двойной щелчок по строке
  тоже открывает карточку.
- Карточка — диалог: поля сверху вниз по порядку заполнения, права —
  строками настроек с переключателем справа, опасное («Удалить профиль») —
  слева внизу, отдельно от «Отмена / Сохранить».

## Что было смешано

- Блок присутствия в два столбца стоял между счётчиками и поиском и сдвигал
  список на треть окна. Стал строкой над таблицей.
- Полоса счётчиков и отдельная строка сортировки из самодельных кнопок —
  стали одной панелью инструментов.
- Права в карточке были цветными карточками внутри окна: включённое право
  заливалось зелёным, у игр — зелёная и красная кнопки. Теперь строки с
  переключателем; у игр — переключатель из трёх положений.
- «Изменить» стояло рамочной кнопкой в каждой строке — теперь появляется при
  наведении, как во всех таблицах программы.

## Найдено и исправлено

- Если роли сотрудника нет в списке ролей (сотрудник заведён до
  справочника ролей), поле «Роль» показывало первую роль — «Администратор».
  Теперь показывается настоящая роль с пометкой «нет в списке ролей».

## Что осталось в двух местах (записано, не менялось)

- Роли описываются в Настройках → «Роли сотрудников», а назначаются здесь.
- Подпись можно править здесь (у любого сотрудника) и в Настройках → «Моя
  подпись» (свою).
- Переключатель «быть в сети» — в Настройках → «Общие», список присутствия —
  здесь.
