# E3Flux

Назначение — получить атрибуты E3.series по оборудованию проекта в виде
книги Excel, вести справочник этих атрибутов и каталог типовых решений E3 и
показать, какое решение подобрано каждой позиции проекта.

## Что на экране

- Вкладка «Атрибуты проекта»: таблица «позиции проекта × атрибуты E3»
  (только чтение), отбор слева, «Скачать Excel».
- Вкладка «Справочник атрибутов»: список атрибутов, карточка атрибута,
  загрузка «Списка атрибутов» из Excel с планом, отмена последней загрузки.
- Вкладка «Типовые решения»: слева разделы каталога (Решения, Признаки,
  Правила, Обозначения, Подбор по проекту), справа рабочая область.
  «Решения» — список с отбором, карточка решения, добавление вручную, загрузка
  классификатора из Excel с планом, отмена последней загрузки, «Скачать
  Excel». «Признаки», «Правила», «Обозначения» — таблицы с правкой в
  диалоге. «Подбор по проекту» — профиль проекта и таблица позиций.
- Вкладка «Схема»: три колонки — что выгружать, холст листа, свойства
  выбранного. Выгрузка в E3 и «Демонстрация» неактивны с объяснением, пока
  нет настольной версии и моста.

## Раскладка

- Шапка: «E3Flux · <проект>» · вкладки. Проект берётся из общего выбора
  проекта оболочки, как у Оборудования.
- «Атрибуты проекта»: слева отбор 256 px (установка, типы Flux со
  счётчиками, «только с тегом», заголовок «имя E3 / описание», листы «на
  тип / один»); справа панель инструментов 40 px — счётчики словами и
  главная кнопка «Скачать Excel», ниже таблица. Подсказка о цвете ячеек — в
  нижней строке.
- Таблица: строка 32 px, шапка 28 px. Столбцы без «Да» — серый заголовок,
  ячейки пустые. Ячейка с «Да», у которой в проекте нет данных, — янтарный
  фон: это единственное цветное место таблицы. Атрибут, не относящийся к типу
  позиции, остаётся пустым без подсветки. Показано не больше 500 строк, в
  книгу попадают все.
- «Справочник атрибутов» — панель Каталога без изменений (`E3AttributesPanel`).
- «Типовые решения»: левый список 208 px (пункт 32 px, счётчик справа); в
  шапке раздела вторичные действия тихие («Скачать Excel», «Добавить»,
  «Отменить загрузку»), главная — «Загрузить из Excel». В «Признаках»,
  «Правилах» и «Обозначениях» главная кнопка — «Добавить …». Читателю без прав
  кнопки правки и загрузки не показываются, а диалоги открываются только на
  чтение. Права — те же, что у справочника атрибутов (правка и загрузка
  справочников каталога).
- «Подбор по проекту»: слева 256 px — установка и профиль проекта (ответы на
  признаки «из профиля»; правка тут же пересчитывает таблицу, запись — кнопкой
  «Сохранить профиль», у профиля своя версия); справа панель инструментов с
  поиском и фильтром «Все · Подобрано · Нужен ответ · Решения нет», ниже
  таблица «позиция, тип, решение, состояние» (точка и слово). Строка открывает
  окно: ответы на признаки с источником (вручную, подбор ОВ, профиль,
  раскладка), кандидаты или ближайшие решения. Позиции без типового решения по
  природе (шумоглушитель) не попадают в таблицу и считаются одной строкой
  внизу. Показано не больше 500 строк.
- «Типы и классы» — шестой пункт левого списка «Типовых решений»: таблица
  «тип Flux, классы классификатора, решений», строка открывает окно с флажками.
- «Схема», верхняя панель 40 px: слева состояние связи с E3 точкой и словами
  («Выгрузка в E3 — только в настольной версии Flux» в браузере), справа
  «Демонстрация» (тихая) и «Выгрузить в E3.series» (главная); обе неактивны, с
  подсказкой «Нужна настольная версия Flux на компьютере с E3.series».
- «Схема», колонки: слева 256 px (вид «по установкам / по типам», поиск,
  профиль проекта одной строкой, группа с флажком, узел 32 px: тег, решение,
  знак состояния ○ ● ◐ ✕ ? ! ⇄, внизу «не участвуют в схеме: N»); в середине
  панель инструментов («Разложить», формат листа А4/А3/А2, масштаб «вписать /
  крупно», «Не помещается: N») и холст; справа 256 px — карточка узла
  (решение, признаки с источником, атрибуты с «Да», обозначение, связь).
- Холст: лист в миллиметрах, по умолчанию А3, рабочее поле внутри рамки, штамп
  серым («занято»: туда блок не ставится), сетка 5 мм. Блок — прямоугольник
  условного габарита с тегом, знаком и ID решения; тянется с привязкой к
  сетке и после этого считается поставленным руками; рамка установки тянется
  целиком. Блок за полем или на занятом — красная рамка и счётчик в панели.
- Порядок вкладок — по ходу работы: сначала то, что скачивают, потом то, из
  чего оно собрано; будущие — последними.

## Книга Excel

Строка 1 — имена E3, строка 2 — описания, данные с 3-й. Столбец A — скрытый
ID позиции Flux: по нему заполненный файл читается обратно. Лист на тип (по
умолчанию) содержит только атрибуты этого типа; «один лист» — все выбранные
столбцы. Логика — `e3/attributeWorkbook.ts`, строки — `src/lib/e3Table.ts`.

## Схема: раскладка и состояние узла

Раскладка — чистая логика `e3/layout.ts` (правила 7.1 проверяет
`scripts/test-e3-layout.ts`), состояние узла — `e3/nodeState.ts`, форматы листа
по умолчанию — `e3/sheetFormats.ts`, команды будущего моста — только типы в
`e3/bridgeTypes.ts`. Положение блоков, формат и снятые флажки хранятся за
проектом в браузере (`flux_e3_scheme:<проект>`, `useSchemeState.ts`): серверного
места для раскладки пока нет, на другом компьютере она не видна. Когда
появятся выгрузки (этап E), положение уйдёт на сервер, а для выгруженного
источником станет E3. Габариты блоков пока условные по типу (кеша из E3 нет).
Порядок узлов — `sourceOrder`; переставить узлы в списке пока нельзя. Линия
(приток/вытяжка) определяется по названию («вытяж…»), общие — рекуператор и
двухуровневые решения.

## Выгрузка в E3 (этап F, на подставном мосте)

Кнопка «Выгрузить в E3.series» открывает окно плана: ошибки (красные) блокируют
выгрузку, предупреждения (янтарные) нет; сводка «поставить N · обновить M ·
заменить K · удалить L · пропущено P». «Выгрузить» запускает запись: окно
показывает «сделано N из M», каждый шаг сразу уходит в журнал выгрузки на
сервере, итог — DONE или «прервана». Над схемой при прерванной выгрузке полоса
«сделано N из M» с кнопками «Продолжить» и «Убрать сделанное»; знак узла после
выгрузки — ● (в схеме) и ◐ (изменился после выгрузки), по связям на сервере.

Без настольной версии кнопки неактивны с объяснением, как и раньше. В
dev-режиме (`FLUX_E3_FAKE=1` при запуске сервера и Vite) «Схема» работает с
подставным мостом `e3/fakeBridge.ts`: «проект E3» живёт в памяти страницы, а над
схемой появляется переключатель «Подставной E3: работает / занят / обрыв на
шаге N» — так можно увидеть и обрыв, и продолжение. Без собранной модели E3 в
клиенте Prisma сервер в dev-режиме хранит связи в памяти (иначе отвечает «нужен
prisma generate»).

Логика: план — `e3/exportPlan.ts` (проверки 8.1, шаги 8.2: блоки → обозначения →
атрибуты → связь последними), сравнение «отправлено / во Flux / в E3» —
`e3/exportCompare.ts` (С1, С2, С5, С7, С10, С16; правка инженера в E3 не
перезаписывается; остальные случаи — этап G), исполнение, продолжение и откат —
`e3/exportRun.ts`. Сервер — `server/routes/e3Exports.ts`, хранилище —
`server/e3ExportStore.ts`, модели `E3Project`, `E3Export`, `E3Binding` во всех
трёх схемах Prisma. Право — `e3.export` (по умолчанию не выдаётся, как права
каталога). Служебный атрибут пишется, только если у него правило спора «Flux
главнее».

## Каталог решений

Каталог — исходник данных (docs/e3-integration.md, 5.0): правка в окне не
требует файла, повторная загрузка файла не перезаписывает правленое вручную
(такие решения план показывает отдельно) и не трогает признаки. Выгрузка
каталога — тот же «Классификатор типовых решений» и «Обозначения» плюс столбец
на признак; заголовок признака кончается его id в скобках, поэтому
выгруженный файл читается обратно без разбора названий. Логика —
`e3/solutions.ts`, `e3/solutionSelect.ts`, `e3/solutionWorkbook.ts`; сервер —
`server/routes/e3Solutions.ts`; позиции для подбора — `src/lib/e3Positions.ts`.
Связь типов Flux с классами файла (`classmap`) правится в пункте «Типы и
классы».

## Что было смешано

Кнопка «Атрибуты E3» стояла в «Выгрузке данных», а вход в справочник — в
Каталоге. Выгрузка в таком виде уберётся, поэтому всё про E3 переехало сюда;
в выгрузке остались только столбцы `e3:` как часть формата шаблона.

## Исключения из общих правил

Нет.

## Логика

Значение ячейки считает та же функция, что у выгрузки оборудования
(`buildEquipmentExchange`), — одно правило на Excel и на E3. Решения и смысл
«Да» — `docs/e3-integration.md`, раздел 5.5.
