# Аудит задания 02: переводчик Flux Office

Состояние на 13.10.2026. Проверка выполнена по `TextTranslationPanel`, текущему
офлайн-движку и памяти переводов, защите технических токенов, Office runtime,
серверному customXML и маршрутам файлов. Окончательный результат зависит от
замороженной сборки GenOffice и живого прогона Word/Excel.

| Требование ТЗ §15–16 | До задания | Текущее состояние |
|---|---|---|
| Офлайн-движок, память и глоссарий | Есть | Используются существующие движок, память и глоссарий; отдельный движок не добавлен. |
| 6 режимов Excel | Нет | Добавлены переключатели и runtime-команды для листа, файла, столбца, строки, ячейки с разделителем и замены; живой save-as ещё не подтверждён. |
| 5 режимов Word | Нет | Добавлены переключатели и runtime-команды для DOCX, страницы, абзаца, строки/таблицы и замены; живой прогон ещё не подтверждён. |
| Область, направление, разделитель и порядок | Частично | Области и настройки доступны в панели и передаются отдельной translation-команде; проверяется в runtime-тестах. |
| Предпросмотр и непроверенные сегменты | Частично | Панель показывает результат перед применением и требует подтверждения непроверенных сегментов. |
| Защита технических токенов и параметров Flux | Частично | Runtime применяет существующий `src/translate/protect.ts`; записи связываются с `sourceId`, `key` и координатами назначения, а запись customXML проходит bounded-валидацию. Нужна проверка native Word/Excel. |
| Обнаружение устаревших переводов и отсутствие дублей | Нет | Журнал содержит ревизию, исходный текст, местоположение и destination; runtime сравнивает состояние источника и историю перед вставкой. Нужен прогон на изменённом источнике и повторном запуске. |
| Атомарность содержимого и метаданных | Нет | Сервер связывает перевод с ограниченным одноразовым токеном и добавляет customXML в финальные байты до CAS. Локальные DOCX/XLSX объединяют часть перед единственной записью. Проверены типы и CAS-claim unit-сценарии; интеграционный прогон сохранения ещё не завершён. |
| Новый файл оставляет оригинал без изменений | Частично | Word сериализует копию из JSON без мутации редактора; Sheets передаёт отдельный typed save-as пакет; hosted/local hosts сохраняют копию. Нужен живой native прогон. |
| Серверный ACL, устаревшая база и replay | Нет | Метаданные проверяются вместе с ACL и base SHA; staged delta ограничена по размеру и обрабатывается одним CAS-сохранением. Unit-проверка покрывает межсерверный доступ, actor/base guard, конкурентный claim, replay и сбой очистки после commit. |

## Ограничения проверки

`npx tsc --noEmit -p .` и `node --import tsx scripts/test-translation-staging.ts`
проходят. `node --import tsx scripts/test-guide-server.ts --office-docs
--office-sheets` пока блокируется отсутствующими пересобранными
`public/genoffice/*` assets. Сборка редактора отложена до заморозки runtime-модулей;
живой прогон native Office и `npm run check:coverage` ещё не выполнены.
