# Codex 10. Вход: скрыть «Вход владельца»

Слова владельца: «Эту фразу нужно убрать со входа: „Выберите файл ключа
владельца и введите пароль к нему. Если основной ключ недоступен, можно
выбрать его резервную копию.“ И „Вход владельца“ — кнопку нужно полностью
убрать, она по умолчанию скрыта, появляется при нажатии комбинации
Shift+Ctrl+Alt».

## Где

`src/components/OwnerLogin.tsx`:

- кнопка — около строки 43;
- фраза — около строки 45;
- подсказка для браузера — около строки 51.

Экран входа, в который встроен этот компонент, найти через `rg OwnerLogin src`.

## Что сделать

1. Убрать фразу про файл ключа.
2. По умолчанию кнопка «Вход владельца» не выводится вообще: её нет в
   DOM, до неё нельзя дойти Tab и её не прочтёт экранный диктор.
3. Одновременное нажатие Ctrl+Shift+Alt на экране входа (keydown с
   `ctrlKey && shiftKey && altKey`) показывает кнопку. Дальше всё работает
   как сейчас.
4. Подсказку «Вход владельца с ключом доступен в приложении Flux для
   Windows» тоже показывать только после комбинации.
5. Обновить описание экрана входа в `docs/methodology/` (найти через `rg`)
   и тесты или фикстуры, которые ищут кнопку или фразу.

## Не трогать

Всё, что не относится к экрану входа.

## Проверки перед PR

- `npx tsc --noEmit -p .`, `test-architecture`.
- UI-тест: по умолчанию кнопки и фразы нет, после Ctrl+Shift+Alt кнопка
  есть и вход владельца открывается.

## Готово, когда

Фразы нет, кнопка появляется только по Ctrl+Shift+Alt, тесты зелёные.
