# Flux 1.19.0 — изменения для сотрудников

* Теги открывают панель переходов; дочерние позиции оборудования показаны отдельными ветвями, включая приводы клапанов.
* «Выгрузка данных» получила перемещаемое окно с таблицей, формулами, группировкой и сохраняемыми шаблонами; в редакторах появился раздел Flux.
* Каталог поддерживает виды оборудования, изготовителей, импорт Excel и 76 исполнений приводов НЕМАН; характеристики можно брать из XML, каталога или сочетать источники.
* Исправлены конфликты сохранения документов и PDF, сохранение копий таблиц и PDF и повторное сохранение исходника после копии.
* Добавлен Архиватор: ZIP/7z, пароли, просмотр, проверка, распаковка с предпросмотром и изменение отдельной копии архива.
* Лицензии выдаются сотрудникам; при истечении срока остаётся чтение. Доверенные настройки и публикация подписанных обновлений через БД доступны владельцу.
* Улучшены защита сессий, обращения и автоматическое выявление сбоев; связь с разработчиком открывает Телемост.
* Требуется повторный вход. Первое развёртывание защиты требует открытых ключей из Flux-Owner и настройки HTTPS-сервера компании; зеркало Windows запланировано на следующий этап.

## Проверки и ограничения

Проверены типы, архитектура, сборки фронтенда/сервера/Electron, разбор каталога,
импорт и отмена Excel, источники параметров, иерархия оборудования, обновление
книги и базовый сценарий программы. Автоматическая диагностика проверена
через API с разными правами. Работа с корпоративным почтовым сервером и запуск portable на
реальном Windows требуют отдельной проверки. Каталожные карточки приводов
содержат отметки о неполных данных исходного PDF; пробелы не заполнены догадками.

Подробности: [Каталог и выгрузки](catalog-and-export.md),
[Проект проводника Windows](windows-explorer-mirror.md).
