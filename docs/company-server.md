# Общая база MariaDB для Flux и Flux Owner

Для текущего подключения используйте существующую MariaDB компании. Рабочая станция должна иметь сетевой TCP-доступ к MariaDB на порту `3306`, а учётная запись приложения — права на выбранную базу и необходимые таблицы. URI вида `mysql://USER:PASSWORD@HOST:3306/Flux` содержит имя пользователя, пароль, адрес и имя базы. Это URI SQL-подключения, а не HTTPS-адрес.

Не используйте в инструкциях и переписке реальные пароли. В URI специальные символы в имени пользователя и пароле должны быть percent-encoded. Выдайте приложению отдельную учётную запись БД с нужными правами; `root@localhost` из phpMyAdmin не является учётной записью приложения. Если phpMyAdmin показывает MariaDB через локальный UNIX socket, это не подтверждает, что сервер принимает сетевые TCP-подключения или что у пользователя есть права для подключения с рабочей станции.

## Подключение владельца с Windows portable

Используйте Flux `1.20.3` и Flux Owner `1.2.0` в portable EXE. Положите оба файла в одну папку и запустите Flux Owner. Откройте уже созданное новое хранилище владельца его паролем; повторно создавать ключи не нужно. В разделе «Подключение» введите URI MariaDB, например `mysql://USER:PASSWORD@HOST:3306/Flux`, и нажмите «Подключиться».

Flux Owner найдёт Flux portable в той же папке и незаметно запустит его локальную серверную часть. Если автоматический поиск не сработает, программа предложит выбрать EXE. Локальный сервер нужен Owner для авторизованного API и публикации. Устанавливать Node.js, настраивать SSH или ставить службу на NAS не требуется. Окно обычного Flux для этого способа не запускается.

Для самостоятельной работы в настольном Flux откройте панель подключения, выберите «Общая база данных», укажите URI MariaDB и сохраните настройку. Перезапустите Flux, чтобы встроенный сервер подключился к базе. Не путайте URI базы с адресом API.

## Расширенный вариант: общий HTTPS API

Если компания уже развернула общий сервер Flux за HTTPS reverse proxy, Owner можно подключить к его API по адресу `https://...`. Это отдельный вариант для общей серверной установки: API обслуживает Flux server, а не MariaDB напрямую. URI SQL не является HTTPS и не должен вводиться в поле HTTPS API. Для прямого подключения к базе используйте описанный выше portable-сценарий.

Не публикуйте MariaDB или внутренний API в Интернет. Ограничьте TCP-доступ к порту `3306` корпоративной сетью/VPN и используйте отдельную учётную запись приложения. Успешное подключение к phpMyAdmin с самого сервера не заменяет проверку сетевого доступа с компьютера, где работают Flux и Flux Owner.

## Обновления

Flux Owner публикует обновления существующим комплектом ключей владельца. Сам Flux Owner обновляется вручную отдельным portable EXE. Если установленная сборка Flux содержит другие открытые ключи, новые лицензии или подписи она не примет: сборку нужно установить вручную с актуальными ключами, а лицензии выпустить заново.
