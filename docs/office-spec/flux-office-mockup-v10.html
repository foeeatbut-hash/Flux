Какой параметр вставить

Объединить параметры разных типов

Выделите две соседние ячейки шапки: обычный щелчок по первой, затем Shift + щелчок по второй. Нажмите правой кнопкой → «Объединить в один столбец». Это не сложение: для каждой позиции будет взято её подходящее значение.
