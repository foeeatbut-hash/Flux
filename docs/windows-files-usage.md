# Файлы Windows в Flux

В portable Проводник и рабочий стол используют настоящие папки текущего
пользователя Windows. В браузере остаётся проектный архив: браузеру нельзя
выдать произвольный доступ к диску. Старые проектные документы не удаляются;
они доступны через «Документы проекта».

## Где находится файл

Обычный файл редактируется в своей папке Windows. «Только в Flux» означает
локальный черновик на этом компьютере. При создании запоминается открытая
папка; «Отобразить в Windows» сохраняет файл туда без повторного выбора пути.
Черновик переживает перезапуск Flux. При совпадении имени публикация сообщает
о конфликте и предлагает другое имя, существующий файл не заменяется.

Содержимое личных файлов и черновиков не отправляется на сервер компании при
открытии, редактировании, сохранении или публикации. Локальные теги, ревизия,
ответственный и ссылки на проекты записываются отдельно от содержимого файла.
Названия доступных проектов и тегов поступают из общей базы.

## Сохранение и конфликты

Flux проверяет исходные байты перед записью. Если файл изменили в Word,
Проводнике или другом окне Flux, редактор сохраняет пользовательские правки
и показывает конфликт. Отдельная копия сохраняется в той же папке;
«Обновить» загружает исходник только после успешного сохранения. Ошибка
сохранения оставляет окно открытым.

DOCX, XLSX и PDF открываются во встроенных редакторах. Текстовые файлы
редактируются в UTF-8 с сохранением BOM и Windows-окончаний строк. Другую
кодировку нельзя молча заменить пустым или повреждённым текстом: такие файлы
доступны через программу Windows. Остальные форматы открываются штатной
программой. «Сохранить копию» сохраняет исходный файл без изменений.

В режиме истёкшей лицензии доступно чтение; запись, создание, удаление,
переименование и изменение свойств требуют действующей лицензии и сессии.
Проверку выполняет главный процесс программы по адресу настроенного сервера.

## Папки, корзина и ограничения

Копирование папок проверяет дерево до записи. Перенос проверяет копию и
отправляет исходную папку в корзину Windows, чтобы можно было восстановить
её при сбое. Удалённые черновики помещаются в отдельную локальную корзину.
Ссылки и junction не обходятся автоматически: папку назначения подключают
явно. Файл с совпадающим именем никогда не перезаписывается скрытно.

Чтение и редактирование ограничено 64 МБ на файл. Для папок предел составляет
5000 элементов, 512 МБ и 64 уровня вложенности. Список папки выдаётся
страницами по 500 элементов; при превышении 50 000 элементов показывается
ограничение. Эти пределы предотвращают зависание интерфейса и позволяют
понятно отказаться от слишком большой операции.

Windows-ветка сохранения использует ReplaceFileW для сохранения прав доступа,
атрибутов и дополнительных потоков исходника. Работа с заблокированными
файлами, OneDrive, сетевыми папками и настоящей корзиной дополнительно
проверяется на Windows; Linux-проверка не подтверждает эти особенности ОС.
